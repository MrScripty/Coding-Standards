# Milestone 7 Row 24 Full-Review Prompt Decomposition

## Owner Contract

`workflows/planning.md` is the sole normative owner for this planning-only
entrypoint. The prompt may preserve the requested full-codebase standards-review
intent and route readers through `STANDARDS-ROUTER.md`, but it cannot own plan
artifacts, findings, decomposition, delegation, acceptance, or implementation
procedure.

Implementation applies only when later work edits repository artifacts.
Verification owns acceptance claims, and Documentation owns durable knowledge;
neither creates a second prompt authority. Missing routing or planning authority
is `unavailable`. The prompt must not copy legacy procedure as a fallback.

## Exact Dispositions

`STD-0849`, `STD-0850`, and `STD-0851` become `index` dispositions to
`workflows/planning.md`. Existing canonical Planning contracts already cover
the useful intent, artifact model, and process, so no normative movement is
required.

## Ordered Children

The prompt, dispositions, focused fixtures/checker, plan, ledger, and affected
shared cursor assertions are the only allowed implementation write set.

implementation authority, machine-specific paths, copied canonical procedure,
more than one disposition per identifier, or files outside the approved write
set.
