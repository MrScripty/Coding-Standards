# Documentation Standards

This file is a migration index for existing links.

- The [Documentation Workflow](workflows/documentation.md) owns durable
  documentation selection, profiles, placement, traceability, and quality.
- The non-normative
  [Documentation Recipe](reference/recipes/documentation.md) contains comment,
  Markdown, public-interface, and algorithm examples.
- The [Release Workflow](workflows/release.md) owns changelog applicability,
  content, collection, and release-time assembly.

This index has no independent normative authority and cannot override its
canonical owners.
