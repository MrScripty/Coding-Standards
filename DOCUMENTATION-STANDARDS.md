policy is owned by the [Documentation Workflow](workflows/documentation.md);
select applicability through the [Standards Router](STANDARDS-ROUTER.md). This
file owns no documentation rule, changelog rule, default, or example. It also
owns no fallback authority.

diagnostic instead of using prior wording from this file.
