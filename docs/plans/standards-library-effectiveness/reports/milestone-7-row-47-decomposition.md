profile applies, required semantic content, artifact placement, traceability,

`boundary-readme` or `contract-readme`.

invent unknown facts, preserve a universal directory README requirement, or

## Typed Outcomes And No Fallback

unresolved diagnostic. Contradictory profile or artifact authority is

placeholder `None` text, invent contract facts, accept an unrelated artifact,
or restore the frozen template as a fallback.
