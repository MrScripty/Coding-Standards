and proposal previews return exact captured navigation content, explicitly
separate from normative policy authority. Callers select canonical destination
IDs; the Engine owns source registration, relative links, fixed non-normative
rendering, candidate projection, verification, and local publication.

binds the accepted/proposed representation, declared destination checks, and
selected canonical owner content. No fake normative policy changes or coverage
attestations are introduced. Existing immutable revision, authorization,
readiness, stale-state, and recovery mechanics remain authoritative.

Explicit retarget dispositions replace obsolete legacy destinations in declared
required-link checks for the edited index. They preserve unrelated assertions
and reject unused, duplicated, stale, or unselected destinations. The admission
report records the discovered consumer scope; checks were not disabled to make
an incomplete index pass.

revisions remain unchanged. Old captured authority without the registration
