# Documentation Cleanup And Coverage Review

## Scope

The cleanup archives 20 accepted or superseded plan bundles and two older
completed standalone plans. The active standards-library restructure plan,
ledger, issues, and milestone reports now share one directory. Evaluation
navigation is separated from the detailed verification guide. The metadata
schema and library architecture decision are colocated with their owners.

Document links, registered evidence locators, and matching suite assertions
follow the moves. Three broken guidance links are corrected. No standards
policy is added, removed, or given a different meaning. Legacy standards
indexes remain because registered suites and the unfinished restructure still
consume them; their retirement is not implied by this archival operation.

Frozen evaluation observations, prompt snapshots, and non-Markdown historical
inventories retain their original bytes. Archived Markdown retains its
historical claims and commit identities while updating navigation; retired
implementation paths are identified as historical locators.

## Coverage Review

The user authorized direct documentation and path/projection changes after
the Engine rejected snapshot creation with `SNAPSHOT.CONTENT_ID_COLLISION`.
The cleanup does not repair or bypass the Engine's durable state.

Before the cleanup, all 51 registered policy-unit coverage requirements were
covered. Moving the documentation consumers changes their compiled provider
and evidence fingerprints, so the old requirement identities no longer apply.
The replacement coverage records are based on the following review:

- All 51 subjects, owners, semantic revisions, policy representation digests,
  structural digests, relationship kinds, applicability programs, and fact
  schemas match their pre-cleanup values.
- The policy-impact catalog and every relationship declaration match their
  pre-cleanup values after applying only the reviewed document path mapping.
- Existing coverage evidence and explicit exclusions remain available at
  their relocated paths. Prior audit conclusions remain historical evidence;
  this review supplies the path-migration conclusion.
- All 271 registered verification suites passed after the document moves and
  matching path assertions were updated. No suite or decision case was removed.
  The root README structure contract now permits the maintenance navigation.

Requirement identities are derived through the existing coverage compiler.
The new audit principal is limited to the existing repository coverage-review
capability. The review does not create new consumer relationships or change
standards applicability, semantic revisions, or enforcement outcomes.

## Final Validation

All 271 registered suites pass, all 51 coverage requirements are current and
covered, and the generated suite-input projection matches the staged file
inventory. Non-fixture Markdown file links resolve; the plan template's ledger
and issue links intentionally refer to files created when instantiating it.
Frozen baselines, prompt snapshots, and archived non-Markdown evidence match
their pre-cleanup bytes.
