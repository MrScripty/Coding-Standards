# Issues: Contract Authority Scope

## Open

- `none`

## Resolved

- The existing concern-boundary rule says when concerns should separate but did
  not require an admission record before a canonical artifact accumulated
  several independently changing authorities.
- General version-scope guidance existed only inside Cross-Language Contract
  Selection, leaving same-language schemas and other contract artifacts without
  the same explicit protection.
- Generated-contract semantic closure identified declaration and executable
  owners but did not prevent declaration placement from being treated as a
  transfer of unrelated domain authority.
