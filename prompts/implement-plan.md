# Plan Implementation Prompt

Implement the active plan in validated slices.

1. Read `CORE-STANDARDS.md`, `STANDARDS-ROUTER.md`,
   `workflows/planning.md`, `workflows/implementation.md`, and the routed
   profiles/topics.
2. Inspect repository status before each slice.
3. Confirm one next slice, exact write set, preserved contracts, and acceptance
   gate.
4. Implement source and focused tests/fixtures together.
5. Run the routed verification at the objective's required fidelity.
6. Keep `plan.md` current; put dated details in `execution-ledger.md` and
   findings in `issues.md`.
7. Replace superseded decisions instead of appending competing authority.
8. Review the staged diff and create one atomic conventional commit.
9. Stop and re-plan when scope, ownership, objective, risk, or required evidence
   changes.

Do not mark `Implemented` work accepted until objective evidence passes. Do not
rewrite shared history or delete user work without explicit authority.
