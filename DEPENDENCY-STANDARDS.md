# Dependency Standards Migration Index

Dependency requirement, ownership, candidate selection, resolution,
provisioning, compatibility, lifecycle, feature and footprint, audit, and
automation authority is canonical in [Dependencies](topics/dependencies.md).

Use [Licensing](topics/licensing.md) for third-party legal obligations,
[Security](topics/security.md) for trust and vulnerability response,
[Performance](topics/performance.md) for measured resource claims,
[Release](workflows/release.md) for published artifacts and consumer
acquisition, and [Verification](workflows/verification.md) for evidence kinds,
environments, and execution schedules.

Language and framework profiles own mechanism-specific adaptation only. This
file is a non-normative migration index and does not preserve legacy matrices,
thresholds, commands, checklists, or CI recipes as alternate policy.
